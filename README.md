# DisasterRX

> Simple static front-end for DisasterRX — an informational demo.

## Project Structure

- `index.html` — main entry point / single-page site

## Overview

This repository contains a small static website (single HTML file) that demonstrates the DisasterRX landing page. It is intended to be opened in a browser or served from a simple static file server.

## Usage

Open `index.html` in your browser, or run a local static server:

Windows (PowerShell):

```
python -m http.server 8000

# then open http://localhost:8000/DisasterRX/ in your browser
```

Alternatively, use any static server or IDE preview extension.

## Development

- Edit `index.html` directly.
- Refresh the browser to see changes.
